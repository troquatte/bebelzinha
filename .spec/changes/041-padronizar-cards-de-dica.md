# 041-padronizar-cards-de-dica

## Objetivo

Corrigir inconsistências visuais dos blocos de dica e aviso, especialmente o disclosure de afiliados em desktop/mobile.

## Critérios de aceite

- [ ] Aviso de afiliados usa ícone + conteúdo agrupado.
- [ ] Aviso de afiliados possui título visual de contexto.
- [ ] Dica de Compras usa o mesmo padrão compartilhado.
- [ ] Dica da Home usa o mesmo padrão compartilhado.
- [ ] Texto quebra naturalmente no mobile sem desalinhamento do ícone.
- [ ] Ícone mantém tamanho fixo e não comprime o texto.
- [ ] Conteúdo textual usa min-width 0 para evitar overflow.
- [ ] Texto legal de afiliados permanece intacto.
- [ ] Nenhuma dependência nova é adicionada.
- [ ] Build Angular validado pelo CI.
- [ ] Entrega publicada em main.
- [ ] main e development equalizadas.
