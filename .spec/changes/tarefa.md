# Tarefa — Restaurar ícones do app

## Modo

FULL

## Necessidade

Restaurar os ícones Material Symbols que haviam sido substituídos por caracteres/emoji em elementos funcionais da interface.

## Requisitos

- menu desktop e mobile com Material Symbols;
- ações principais com ícones reconhecíveis;
- manter emojis apenas quando decorativos ou parte da linguagem da Bebel;
- reutilizar a fonte Material Symbols já carregada;
- criar padrão compartilhado para ícone + texto;
- não adicionar dependência;
- validar build e publicar em main;
- equalizar main e development.
