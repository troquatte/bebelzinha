# Cinco coisas para conferir antes de sair para o mercado

## Narração
Antes de sair para o mercado, confira cinco coisas, minha filha! Um: geladeira e despensa, para não comprar o que já tem. Dois: as refeições que pretende fazer, para os ingredientes terem destino. Três: quantas pessoas vão comer e as quantidades das receitas. Quatro: a lista completa, incluindo limpeza e higiene. Cinco: as sacolas reutilizáveis. Pronto! Agora você vai procurar o que falta, em vez de tentar lembrar de tudo no corredor!
