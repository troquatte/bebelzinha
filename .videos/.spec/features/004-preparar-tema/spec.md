# Preparar tema antes de renderizar

Usuário autoriza roteiro, imagens e voz quando habilitada a partir de um único prompt; renderização da fila é pedido separado. Entrada humana: tema/duração ou ID para retomada. Criatividade pelo agente, sem API adicional de LLM ou promessa de execução CLI autônoma.

Aceite: próximo ID livre sem sobrescrever; roteiro com fala isolada e direção por cena; reutilização antes de gerar imagem, identidade da Bebel ancorada em referências; arquivos realmente copiados ao banco correto; versões preservadas; voz fornecida ou ElevenLabs explicitamente autorizado pelo prompt quando habilitado; sem áudio não finalizar timeline; render não chama geração; fundo mesmo nome-base prioriza vídeo sobre imagem automaticamente e invalida cache; pendências exatas, sem genéricos; guia simples para equipe.

Limpeza restrita aos prompts duplicados criar-cena/proxima-cena. Preservar mídia, diagnósticos, CTA e protótipo. Sem previews/relatórios/SDD por produção, aprovação ou publicação.
